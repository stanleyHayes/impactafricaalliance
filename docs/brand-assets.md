# Brand Assets

The IAA logo and colours follow the approved brand identity exported in the two
source brand-identity images in [`docs/brand-assets/`](brand-assets/)
(`brand-identity-1.jpeg` and `brand-identity-2.jpeg`).

Colour and typography tokens live in code at
[`packages/shared/src/constants/brand.ts`](../packages/shared/src/constants/brand.ts) — import
from `@iaa/shared`, never hard-code hex values.

## Approved palette

| Token | Hex | Usage |
|---|---|---|
| Deep forest | `#001E14` | Primary dark backgrounds, footer, hero overlays |
| Mint / electric aqua | `#00FCAA` | Primary accent, CTAs, text on dark, focus rings |
| Gold / amber | `#FFC300` | Secondary accent, highlights, emphasis |
| White | `#FFFFFF` | Light text and surfaces |
| Green gradient | `#001E14` → `#00FCAA` | Hero / section fills |
| Gold-green gradient | `#FFC300` → `#00FCAA` | Accent gradients |

## Typography

- **Headings:** Poppins Bold (700)
- **Body:** Poppins Regular (400)
- Loaded from Google Fonts in `apps/marketing/index.html` and `apps/admin/index.html`.

## Logo variants (processed, committed)

Generated by [`tools/process-brand-assets.mjs`](../tools/process-brand-assets.mjs) into
`apps/marketing/public/brand/` and `apps/admin/public/brand/`. Each is trimmed, resized, and
emitted as both `.png` and `.webp` (with a `@240` half-width variant for retina headers).

| File | Use on | Notes |
| --- | --- | --- |
| `logo-primary.{png,webp}` | Light backgrounds (header, off-white sections) | Full-colour gradient mark + charcoal wordmark |
| `logo-white.{png,webp}` | Dark green / gradient / photo backgrounds (footer, hero) | Reversed white logo |
| `logo-emerald.{png,webp}` | Single-colour contexts | Emerald monochrome |
| `favicon-32.png`, `apple-touch-icon.png`, `icon-512.png` | Browser tab / PWA / mobile | Symbol-only crop of the mark |
| `og-image.png` | Social sharing | 1200×630 Open Graph image generated by `tools/generate-og-image.py` |

Rules: never distort, rotate, or recolour; min width 120px desktop / 90px mobile;
keep clear space around the mark.

## Source files

The raw brand-identity exports (`IAA BRAND IDENTITY-*.zip`, ~7.4 MB of high-res PNG/JPG) are **not
committed** (see `.gitignore`). Keep the originals in the team's shared drive. To regenerate web
assets, place the unzipped `IAA BRAND IDENTITY/` folder at `.brand-extract/` in the repo root and
run:

```bash
node tools/process-brand-assets.mjs
```

| Source export | Mapped to |
| --- | --- |
| `20260501_230203.png` | `logo-primary` + favicons |
| `20260501_230307.png` | `logo-white` |
| `20260501_232445.png` | `logo-emerald` |
| `20260501_230301.jpg` | Reference: white logo on gold→green gradient (hero inspiration) |

## Regenerating the Open Graph image

```bash
python3 tools/generate-og-image.py
```

This writes `apps/marketing/public/brand/og-image.png` (1200×630) using the approved deep-forest,
mint, and gold palette.
