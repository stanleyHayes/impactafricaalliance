# Brand Assets

The IAA logo and colours follow §2 of [`website-specification.md`](website-specification.md).
Colour and typography tokens live in code at
[`packages/shared/src/constants/brand.ts`](../packages/shared/src/constants/brand.ts) — import
from `@iaa/shared`, never hard-code hex values.

## Logo variants (processed, committed)

Generated by [`tools/process-brand-assets.mjs`](../tools/process-brand-assets.mjs) into
`apps/marketing/public/brand/` and `apps/admin/public/brand/`. Each is trimmed, resized, and
emitted as both `.png` and `.webp` (with a `@240` half-width variant for retina headers).

| File | Use on | Notes |
| --- | --- | --- |
| `logo-primary.{png,webp}` | Light backgrounds (header, off-white sections) | Full-colour gradient mark + charcoal wordmark |
| `logo-white.{png,webp}` | Dark green / gradient / photo backgrounds (footer, hero) | Reversed white logo |
| `logo-emerald.{png,webp}` | Single-colour contexts | Emerald monochrome |
| `favicon-32.png`, `apple-touch-icon.png`, `icon-512.png` | Browser tab / PWA / mobile | Symbol-only crop of the mark |

Rules (from the spec): never distort, rotate, or recolour; min width 120px desktop / 90px mobile;
keep clear space around the mark. The hero gradient runs **gold → forest green** (left → right),
matching the brand lockup.

## Source files

The raw brand-identity exports (`IAA BRAND IDENTITY-*.zip`, ~7.4 MB of high-res PNG/JPG) are **not
committed** (see `.gitignore`). Keep the originals in the team's shared drive. To regenerate web
assets, place the unzipped `IAA BRAND IDENTITY/` folder at `.brand-extract/` in the repo root and
run:

```bash
node tools/process-brand-assets.mjs
```
